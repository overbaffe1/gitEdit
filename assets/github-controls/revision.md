# Карточка экспоната

Учебный документ для демонстрации rich diff, не журнал реальных изменений проекта.

Режим показа: **нативная интерактивная карта**.

| Свойство | Значение |
|---|---|
| Управление | Перемещение и масштаб |
| Формат | GeoJSON |
| Исполнение своего JS | Не требуется |

1. Открыть карту.
2. Переместить вид.
3. Изменить масштаб.

**Новая заметка:** это пример замены текста, изменения таблицы и добавления пункта списка.
