Нитяная луна

Один маршрут, без разрывов. Закрепи нить на гвоздике 000. Нажимай «Дальше» после каждого законченного перехода. Нумерация по часовой стрелке, 000 сверху.

Прогресс не сохраняется автоматически. Запиши номер шага перед закрытием. Рисунок — схематические линии, не фотометрическая модель PNG. Здесь нет сети и автопроигрывания; на GitHub HTML показывается как исходник. Скачай файл и открой локально.
