# Качение без GIF: пять точных соотношений в SVG

18 ноября 2026. Новый приём оформления — показать **механизм построения**, а не только готовую кривую. Все пять экспонатов состоят из неподвижной опоры, катящегося колеса, отмеченной точки и уже вычисленной траектории. Скрипт нужен при печати файлов; на странице README исполняется только CSS-анимация изображения, не Python или JavaScript.

## Что изучено в других репозиториях

- В [SVG.js / Timeline.js](https://github.com/svgdotjs/svg.js/blob/4b8809b1554c44a84f8992cdbda60480336cc040/src/animation/Timeline.js) посмотрены устройство временной шкалы, источник времени `performance/Date.now`, методы завершения и паузы. Это полноценная JS-библиотека анимации, полезная для отдельного приложения, но не код, который можно положить внутрь README и запустить.
- В [Mathigon / circles/functions.ts](https://github.com/mathigon/textbooks/blob/232ec42eca86c00997d5712a01e5b2768475a83d/content/circles/functions.ts) просмотрены начало урока и функции `radius`/`similar`: кнопка запуска, последовательность построений, перетаскивание и проверка результата. Они зависят от платформы Mathigon и её JS-компонентов. Это не готовый интерактивный виджет GitHub.

Из этого берём принцип: **видимая связь опоры, колеса и точки делает объяснение понятнее одной красивой линии**. Не переносим код, текст урока, графику, шрифты или компоненты этих проектов. Новые геометрия, SVG и генератор написаны здесь отдельно. Ссылки закреплены на просмотренных коммитах; полного аудита библиотек не проводилось.

## Как устроено качение

Для колеса радиуса `r` внутри неподвижной окружности радиуса `R` центр идёт по окружности радиуса `R−r`, а абсолютный поворот колеса равен `−(R−r)t/r`. При начальной отметке снаружи получаем:

```math
x=(R-r)\cos t+r\cos\left(\frac{R-r}{r}t\right),\qquad
y=(R-r)\sin t-r\sin\left(\frac{R-r}{r}t\right).
```

В SVG два вложенных поворота: группа-переносчик делает оборот `t`, локальная группа колеса — `−Rt/r`. В сумме получается нужный абсолютный угол, а не просто декоративное вращение круга. В каждой фазе контактная точка колеса имеет нулевую скорость относительно опоры: это и есть отсутствие проскальзывания.

### Пара Туси, R:r = 2:1

Радиусы 150 и 75. Получается `x=R cos(t)`, `y=0`: точка ходит по диаметру, хотя обе исходные составляющие круговые. Это вырожденная двувершинная гипоциклоида; её отрезок проходится в обе стороны.

[Анимация](../assets/rolling/tusi.svg) · [статичный кадр](../assets/rolling/tusi-still.svg).

### Дельтоида, R:r = 3:1

Радиусы 150 и 50. Малое колесо рисует кривую с тремя острыми вершинами. В конце полного обхода опоры замыкаются и траектория, и ориентация спицы.

[Анимация](../assets/rolling/deltoid.svg) · [статичный кадр](../assets/rolling/deltoid-still.svg).

### Астроида, R:r = 4:1

Радиусы 150 и 37.5. После упрощения формул получаем `x=R cos³(t)`, `y=R sin³(t)`. Видно четыре вершины и связь между круговым движением и характерной вогнутой рамкой.

[Анимация](../assets/rolling/astroid.svg) · [статичный кадр](../assets/rolling/astroid-still.svg).

### Кардиоида, внешнее качение R:r = 1:1

Два одинаковых радиуса 65. Центр колеса идёт по окружности радиуса `R+r`; при отметке на начальном контакте:

```math
x=(R+r)\cos t-r\cos\left(\frac{R+r}{r}t\right),\qquad
y=(R+r)\sin t-r\sin\left(\frac{R+r}{r}t\right).
```

Локальный поворот в SVG теперь положительный `Rt/r`, а абсолютный — `(R+r)t/r`. В отличие от астроиды, колесо снаружи опоры, а не внутри.

[Анимация](../assets/rolling/cardioid.svg) · [статичный кадр](../assets/rolling/cardioid-still.svg).

### Циклоида, колесо по прямой

Круг радиуса 65 за один оборот проходит путь `2πr`. След точки задаётся `x=r(t−sin t)`, `y=r(1−cos t)` над горизонтальной опорой. В координатах SVG ось y направлена вниз, поэтому вертикальная координата в коде имеет противоположный знак.

**Петля намеренно не бесшовная:** после одной арки колесо возвращается слева в исходную позицию. В отличие от четырёх круговых механизмов, перенос по прямой не может вернуться в начало без сброса. Это подписано в карточке; физического разворота колеса в конце нет.

[Анимация](../assets/rolling/cycloid.svg) · [статичный кадр](../assets/rolling/cycloid-still.svg).

## Точность и ограничения

- Линия каждого следа вычислена из формулы в 721 точке. Это полилинейное приближение кривой, не аналитический SVG-объект бесконечной точности.
- Движение задаётся линейными CSS-поворотами, а не последовательностью подогнанных кадров. У всех групп один период 14 секунд, без задержек; соотношения скоростей заложены в углы.
- Стартовая фаза четырёх замкнутых механизмов сдвинута на 0.7 радиана, чтобы в неподвижном состоянии была видна спица. У статичной циклоиды выбран кадр 1.2 радиана.
- Это кинематическая иллюстрация: массы, инерция, трение, контактные силы и упругость не рассчитываются.
- Оранжевая линия видна сразу целиком. Точка показывает, **как её получить**, но не оставляет в браузере накапливающийся след.
- Встроенные надписи используют системный шрифт. Рендеринг CSS-анимации и сглаживание могут различаться между клиентами.

## Уменьшение движения — настоящая статичная версия

Для каждого механизма выпущены **два файла**, а README выбирает неподвижный при системной настройке `prefers-reduced-motion: reduce`. В файлах `-still.svg` вообще нет `@keyframes` или свойств `animation`. Дополнительно в анимированных SVG есть свой CSS media-query на случай открытия файла напрямую.

Пример рабочего блока из корня этого репозитория:

```html
<picture>
  <source media="(prefers-reduced-motion: reduce)" srcset="assets/rolling/tusi-still.svg">
  <img src="assets/rolling/tusi.svg" width="960" alt="Колесо половинного радиуса катится внутри круга, точка движется по диаметру.">
</picture>
```

Используй один механизм как учебную заставку, иллюстрацию математической библиотеки или акцент между секциями. Не выдавай его за свободно вращаемую модель: у изображения нет управления скоростью, перетаскивания или сохраняемого состояния.

## Перепечатать

```sh
python3 atlas/samples/rolling/generate.py
python3 atlas/samples/rolling/generate.py --output /tmp/rolling
python3 -m unittest discover -s tests -v
```

Только стандартная библиотека Python, без сети, Pillow и стороннего SVG-движка. Генератор не редактирует README. Проверки сравнивают чистую генерацию, проверяют касание окружностей, отсутствие проскальзывания, формулы Туси/астроиды, замыкание и наличие настоящих статичных fallback-файлов.

## Необязательная проверка в настоящем браузере

В этом обновлении дополнительно запущен Chromium: для каждого из пяти SVG проверены координаты отмеченной точки в пяти фазах, остановка CSS-анимаций при reduced-motion и реальный выбор `currentSrc` у `<picture>`. Это локальная интеграционная проверка Chromium, не гарантия одинакового поведения всех браузеров или мобильных клиентов GitHub.

[Проверочный скрипт](samples/rolling/check-browser.cjs) оставлен рядом с генератором. Нужны уже установленный Chromium и отдельный `playwright-core`; они не становятся зависимостями самой галереи:

```sh
npm install --prefix /tmp/rolling-browser playwright-core
NODE_PATH=/tmp/rolling-browser/node_modules CHROMIUM_PATH=/usr/bin/chromium \
  node atlas/samples/rolling/check-browser.cjs
```

Подставь свой путь к Chromium. Sandbox браузера по умолчанию включён. В изолированной тестовой среде, где sandbox недоступен, скрипт поддерживает явный `ROLLING_NO_SANDBOX=1`; для обычной машины отключать защиту не требуется. Скрипт создаёт временную HTML-страницу для проверки `picture` и удаляет её после проверки; репозиторий не меняет.
