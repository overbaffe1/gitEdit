# Настоящий аккордеон прямо в GitHub README

[← Попробовать в README](../README.md) · [Переносимый фрагмент TXT](../assets/exclusive-panel/panel.txt) · [Генератор](samples/exclusive_panel/generate.py)

## Находка

`<details>` уже был в галерее. Новое здесь — **одинаковый атрибут `name`** у нескольких секций: браузер связывает их в группу и при раскрытии одной закрывает предыдущую. Никаких переходов между файлами и никаких обработчиков JavaScript.

18 ноября 2026 GitHub Markdown API **сохранил этот атрибут**, добавив одинаковый префикс `user-content-` к имени во всех трёх секциях. Затем HTML именно из ответа GitHub, а не написанный вручную аналог, проверен в локальном Chromium.

В README стоит пример **«Статика / Движение / Исходник»**. Картинки не новые: повторно используются собственные кадры из [демонстрации форматов](motion-formats.md). Это не очередной статичный плакат, а проверка поведения интерфейса страницы.

## Попробовать

1. Изначально раскрыт только «01 · Статика».
2. Нажать «02 · Движение»: первый режим должен закрыться, второй — открыться.
3. Нажать «03 · Исходник»: откроется рецепт, петля исчезнет с экрана.
4. Снова нажать тот же заголовок — **все три секции можно закрыть**.
5. Для клавиатуры: Tab до заголовка, Enter или Пробел. Между заголовками могут встретиться ссылки в открытом содержимом, в том числе обёртки изображений, добавленные GitHub.

Это **аккордеон**, а не полноценные вкладки с `tablist`/`tabpanel`. Стрелки влево-вправо не обещаются, обязательного выбранного режима нет. Используется нативная семантика `details/summary`, без искусственных ARIA-ролей.

## Минимальный рецепт

```html
<details name="my-project-demo" open>
  <summary>Первый режим</summary>
  <p>Начальный экран.</p>
</details>
<details name="my-project-demo">
  <summary>Второй режим</summary>
  <p>Первый закроется при открытии второго.</p>
</details>
```

Для второй независимой группы нужно **другое имя**. Элементы с одинаковым именем связаны в пределах документа, даже если не стоят рядом. Не вставляй две копии примера с одним именем, если хочешь независимое управление.

Начальный `open` нужен лишь у первой секции. `open="false"` не закрывает секцию: это булев атрибут, его надо убрать. Для Markdown внутри HTML-блока оставляй пустые строки после `summary` и перед `</details>`.

Простой рецепт выше не требует изображений и зависимостей. Для **полного примера с кубом** скопируй [panel.txt](../assets/exclusive-panel/panel.txt) в корневой README и сохрани в своём проекте:

- `assets/motion-formats/poster.png` — [файл](../assets/motion-formats/poster.png);
- `assets/motion-formats/cube.gif` — [файл](../assets/motion-formats/cube.gif).

Это два локальных медиафайла плюс Markdown, не self-contained картинка. В README подпапки нужно поправить пути. TXT — обычный исходник для ручного копирования, не запись в clipboard и не кнопка автоматического изменения README.

## Реальные проверки

**Среда браузерного теста:** Chromium `153.0.8010.0`, Playwright Core `1.65.1`, локальный Chromium-пакет `@sparticuz/chromium` `153.0.0`. Бинарники и node_modules лежат в исключённой `.local`, не в Git. Это локальный процесс, не запуск браузера в облачном сервисе.

| Проверка HTML из GitHub Markdown API | 1280 px, обычное движение | 390 px, reduced-motion |
|---|---|---|
| Три секции имеют одно сохранённое имя | Да | Да |
| Начальное состояние `[open, closed, closed]` | Да | Да |
| Мышь: второй закрывает первый, третий закрывает второй | Да | Да |
| Повторный клик закрывает последнюю секцию | Да | Да |
| Enter, Tab, Пробел работают | Да | Да |
| Независимая контрольная группа не закрывается | Да | Да |
| Адрес страницы не меняется | Да | Да |
| В режиме движения выбран правильный источник | `cube.gif` | `poster.png` |
| Выбранный файл успешно декодирован | Да | Да |
| Для переключения не потребовался внешний сервис | Да | Да |

Граница проверки: **HTML, возвращённый официальным Markdown API, открыт локально**. Авторизованный интерфейс github.com, его production CSS, расширения браузера, Safari, Firefox и мобильные приложения GitHub в этой сессии не проверялись. Ширина 390 px — узкий viewport Chromium, не физический iPhone. Это сильнее проверки одного наличия `name`, но не гарантия поведения каждого GitHub-клиента.

В API-тесте одно имя стало `user-content-gitedit-motion-desk-v1` во всех секциях. Не добавляй этот префикс в авторский HTML: это преобразование GitHub. Прочие детали санитайзера могут меняться.

## Совместимость и ограничения

По закреплённым данным MDN BCD, `details.name` поддерживается с Chrome 120, Firefox 130 и Safari 17.2. Это сведения совместимости из источника, **не наши запуски трёх браузеров**. Старый браузер может игнорировать группировку и разрешать открыть несколько секций; содержимое при этом остаётся обычными доступными `details`.

- Начальный экран неподвижный. Анимацию читатель раскрывает сам.
- `picture` выбирает статичный постер при `prefers-reduced-motion: reduce`; это предпочтение системы, не универсальная гарантия для каждого клиента.
- Скрытие GIF не является точной паузой: браузер может продолжать декодирование и заранее загружать закрытые картинки. Не обещаем lazy network или экономию трафика.
- Это записанные кадры, не новый WebGL-viewer и не видеоплеер с перемоткой.
- Высота секций меняется; документ не получает фиксированного размера панели, и прокрутка может смещаться из-за обычной вёрстки.
- Переключение не отправляет форму, Issue или workflow, не сохраняет выбор в аккаунте/репозитории. Сам просмотр GitHub, как обычно, требует сетевых запросов; это не обещание анонимности.
- Здесь нет JS/CSS приложения, localStorage, серверного счётчика или зависимости от платного API.

## Как дошли до находки

Исходно проверялись карта как меню и действия в схемах Mermaid. Поиск репозиториев с соответствующими сочетаниями слов не дал убедительного нового примера. Поэтому вместо объявления «невозможно» проверили документацию и реальный результат санитайзера.

[Шесть закреплённых источников](samples/exclusive_panel/sources.json):

| Источник | Просмотрено и зачем |
|---|---|
| `github/docs`, non-code files | Разделы GeoJSON и Mermaid. Styling, геометрии и карты подтверждены; сам по себе документ не доказывает, что произвольный HTML-link в popup будет навигационным меню. Карта-меню не объявлена готовой. |
| `benbalter/dc-wifi-social`, `bars.geojson` | Начало файла с точками, символами и описательными properties. Это реальный пример данных из официальной документации, но не доказательство выполнения HTML в popup. Ничьи адреса в наш экспонат не переносились. |
| `mapbox/simplestyle-spec`, 1.1.0 | Разделы optional client behavior, title/description, цвета/маркеры. Спецификация говорит о представлении свойств, но не гарантирует интерфейс конкретного GitHub-viewer. |
| `github/markup`, README | Markdown→HTML — лишь первый этап; санитизация и дополнительные фильтры происходят отдельно на GitHub. Поэтому изучение одной библиотеки не заменяет запрос к Markdown API. |
| `mdn/content`, details | `name` описывает настоящую взаимоисключающую группу без скрипта; `open` — начальное состояние. Именно это стало рабочим кандидатом. |
| `mdn/browser-compat-data`, details.json | Закреплены версии поддержки атрибута и честный fallback для старых клиентов. |

Одноразовый API-пробник также показал сохранение `video controls` и `img usemap`, но удалил сам `map/area`. **Наличие отдельного тега/атрибута не доказывает работоспособный плеер или image-map**; эти варианты в README не добавлены и не названы готовыми возможностями. Готовое поведение аккордеона, в отличие от них, проверено кликами и клавиатурой.

## Воспроизведение

Генератор и Python-проверки не требуют сторонних библиотек:

```sh
python atlas/samples/exclusive_panel/generate.py
python -m unittest discover -s tests -p test_exclusive_panel.py -v
```

Генератор обновляет только свой фрагмент, TXT и manifest. Он не переписывает README, workflows, историю Git или прежние картинки.

Отдельная opt-in браузерная проверка требует Node 22+, работающий `gh` с доступом к Markdown API и локальные npm-зависимости:

```sh
npm install --prefix .local/readme-browser --no-audit --no-fund playwright-core@1.65.1 @sparticuz/chromium@153.0.0
node atlas/samples/exclusive_panel/check-browser.cjs
```

В минимальном Linux без NSS/NSPR использован режим с библиотеками из того же локального npm-пакета:

```sh
EXCLUSIVE_PANEL_BUNDLED_LIBS=1 node atlas/samples/exclusive_panel/check-browser.cjs
```

Это не AWS и не включение облачных услуг. Скрипт запускает локальный браузер, берёт ответ `gh api markdown`, перехватывает запросы к тестовому адресу и читает картинки из локального checkout. Доступ к внешним медиа не нужен. Браузерная проверка не запускается автоматически каждым unittest и не добавлена в Actions.
