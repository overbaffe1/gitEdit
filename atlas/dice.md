# Кости без чемпиона

Классические кости Эфрона: честная шестигранная кость не обязана иметь надписи 1…6. Здесь повторяются значения, но каждая из шести **граней** равновероятна. Независимость бросков — предположение модели, а не результат измерения бумажной модели.

| Кость | Шесть граней | Среднее |
|---|---|---:|
| A | 0, 0, 4, 4, 4, 4 | 8/3 |
| B | 3, 3, 3, 3, 3, 3 | 3 |
| C | 2, 2, 2, 2, 6, 6 | 10/3 |
| D | 1, 1, 1, 5, 5, 5 | 3 |

Для одного броска `A → B → C → D → A`, каждая стрелка означает `P(первая > вторая) = 24/36 = 2/3`. Следовательно, самой сильной кости нет: каждой можно противопоставить другую, выигрывающую чаще половины бросков. Это не обещает выигрыш в конкретном броске или конечной серии. Вероятность победить — не математическое ожидание значения: среднее A ниже среднего B, но A чаще выигрывает у B.

## Все вероятности, включая ничьи

Таблица показывает **безусловную** вероятность строгой победы строки над столбцом. Ничья не считается победой и не приводит к перебросу. Диагональ — два независимых броска одинаково размеченных костей, а не сравнение результата с самим собой.

| Один бросок | A | B | C | D |
|---|---:|---:|---:|---:|
| A | 2/9 | 2/3 | 4/9 | 1/3 |
| B | 1/3 | 0 | 2/3 | 1/2 |
| C | 5/9 | 1/3 | 2/9 | 2/3 |
| D | 2/3 | 1/2 | 1/3 | 1/4 |

## Два броска — уже другая игра

Каждый игрок дважды независимо бросает выбранную кость и **складывает** значения. Не максимум, не две победы подряд и не лучшее из двух. У каждого игрока 36 упорядоченных пар граней, вместе 1296 равновероятных исходов.

| Сумма двух | A | B | C | D |
|---|---:|---:|---:|---:|
| A | 8/27 | 4/9 | 16/81 | 4/9 |
| B | 5/9 | 0 | 4/9 | 1/4 |
| C | 11/27 | 5/9 | 8/27 | 5/9 |
| D | 5/9 | 1/4 | 4/9 | 5/16 |

Связи A→B и B→C развернулись; C→D и D→A сохранились. **Весь цикл не разворачивается.** Появляются ничьи даже между разными костями, например A и C. Против C в этом режиме ни одна другая кость не имеет безусловной вероятности победить больше 1/2. Стенд выбирает ответ с наибольшей вероятностью строгой победы (при равенстве — первая буква), но честно предупреждает, если эта вероятность не превышает половину. Утверждение о гарантированном преимуществе второго выбора относится только к одному броску.

## Что открыть

- [Анимация](../assets/dice/cycle.gif) и [полный неподвижный кадр](../assets/dice/proof.png): все четыре связи, сетка 6×6, отдельная клетка для каждой пары граней. Анимация раскрывает **перечисленные** исходы, не изображает случайный эксперимент.
- [Офлайн-стол ZIP](../assets/dice/table.zip): распаковать и открыть `table.html` через `file://`. Без сервера, CDN и сети. Выбор кости, два правила, матрица вероятностей, сетки 6×6 / 36×36, ползунок конкретного исхода и полный пересчёт аудита.
- [Развёртки A4 SVG](../assets/dice/nets-a4.svg): четыре сетки куба, ребро 19 мм при печати 100 %. Внешний контур разрезается, общие рёбра сгибаются; без клеевых клапанов, скрепление лентой изнутри. Это учебная бумажная модель: распределение её реальных бросков не калибровалось, бумага и скотч могут вносить смещение.
- [Грани JSON](../assets/dice/dice.json), [полный аудит JSON](../assets/dice/audit.json), [32 строки точных вероятностей CSV](../assets/dice/pairs.csv).

На GitHub работает GIF и ссылка на пакет, а не встроенный JavaScript. Для reduced-motion предусмотрен неподвижный PNG.

## Две независимые проверки

`exact.py` строит распределение суммы свёрткой целочисленных кратностей. Повторяющиеся числа **не** схлопываются до равновероятных уникальных значений. Для каждой пары сумм произведение кратностей добавляется в победы, ничьи или поражения. Вероятности сокращаются стандартным `Fraction`.

`verify.py` не импортирует `exact.py`: перебирает упорядоченные **индексы** граней, получает список всех 6 или 36 сумм и сравнивает каждый элемент первого списка с каждым элементом второго. Проверяются распределения, все счётчики, сокращённые дроби и лучшие ответы. Всего 16×36 + 16×1296 = **21 312** элементарных исходов. JSON с изменённым счётчиком, дробью, распределением или ответом отвергается; булевы значения не принимаются за целые счётчики.

Это воспроизводимый конечный подсчёт, не оценка Monte Carlo и не криптографический сертификат. Проверка относится к данным в `dice.json`; пользовательские JSON принимаются лишь с четырьмя костями A…D, шестью целыми метками каждой и диапазоном ±100. Ограничение не превращает парсер в универсальную защиту от гигантских недоверенных файлов.

```sh
# Только стандартная библиотека, в том числе из распакованного ZIP:
python3 -S atlas/samples/dice/exact.py assets/dice/dice.json
python3 -S atlas/samples/dice/verify.py assets/dice/dice.json assets/dice/audit.json
# Перерисовать иллюстрации:
python3 -m venv .venv
.venv/bin/pip install -r atlas/samples/dice/requirements.txt
.venv/bin/python atlas/samples/dice/generate.py
.venv/bin/python -m unittest discover -s tests -p test_dice.py -v
```

Только отрисовка требует Pillow 13.0.0. ZIP использует фиксированные даты. Восемь тестов: полный опубликованный аудит, 12 детерминированных случайных наборов против независимого перебора, суммы до четырёх бросков, симметрия и ничьи, порча JSON, строгие входы, GIF/SVG/CSV, автономный ZIP без site-packages и побайтная повторная генерация. Опциональный `check-browser.cjs` проверяет распакованный пакет в Chromium: все восемь ответов, обе полные таблицы, крайний исход ползунка, клавиатуру, сброс, canvas, мобильную ширину и отсутствие сетевых запросов/JS-ошибок. Команды установки его отдельных npm-зависимостей — в начале файла; минимальный Linux требует библиотек Chromium.

## Исследование GitHub

В [sources.json](samples/dice/sources.json) закреплены восемь README и три выбранных файла с SHA. Это не восемь независимых аудитов алгоритмов: часть README очень короткая или шаблонная. Поиск GitHub был тематическим (`nontransitive dice`); чужие приложения не устанавливались и не запускались, код и иллюстрации не копировались. Сам набор Эфрона — известный математический пример, не наша новая находка.

|---|---|

| BartMassey/nontransitive-dice | README и весь `dice.hs`: независимые случайные индексы граней, счётчик строгих побед; ничья даёт ноль. Здесь вместо симуляции — исчерпывающий подсчёт. |
| SteefCoder/nontransitive-dice | README в одну строку о поиске наборов; дерево обнаружило SAT/ILP-программы, их реализация не изучалась. |

| rbrincke/nontransitive-dice | README о выборе вторым, перечислении разметок 1…18 и вероятностях серии. Его большие числа найденных решений и округлённые таблицы здесь не воспроизводятся; в нашей модели только один раунд или сумма двух. |

Экспонат использует README как вход в маленький проверяемый эксперимент: не просто «необычные кости», а смена правила, после которой знакомая стратегия перестаёт работать.
