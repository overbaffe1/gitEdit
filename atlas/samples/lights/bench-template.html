Лампочки с двумя невидимыми печатями

Нажатие меняет клетку и её соседей по стороне. За границей поля соседей нет. Цель — погасить всё. Двойное нажатие отменяется, порядок нажатий не важен.

Розовая точка — место нажатия в выбранном решении. «Минимум» — минимум среди всех четырёх масок. После хода выбранное решение сбрасывается к минимальному. Редактор и кнопки изменения исходных ламп — не разрешённые ходы игры.

Две печати

Чётность числа включённых ламп под каждым узором сохраняется при любом разрешённом нажатии. У погашенного поля обе равны нулю. Если хотя бы одна равна единице, погасить поле нельзя.

Ранг матрицы — 23 из 25. Из 2²⁵ полей решаемы 2²³, ровно четверть. У каждого решаемого поля ровно четыре маски нажатий, но не обязательно четыре различных минимальных решения.

Проверка воспроизводит только обратимые операции строк, проверяет приведённую матрицу и обе печати. Редактор позволяет создавать все четыре класса чётности, а игровые ходы не выходят из своего класса.
