Это **схема просмотра, не географическая карта**. Цвет дублируется буквами A/B/C и номерами; станции внутри картинки не кнопки. Открывай экспонаты по ссылкам:

**A · Линия света:** [01 Гравюра](atlas/printroom.md) → [02 Розетки](atlas/afterlight.md) → [03 Нитяная луна](atlas/threadmoon.md).

**B · Линия объёма:** [04 Стереограмма](atlas/stereogram.md) → [05 Бумажный кристалл](atlas/relief.md) → [06 Материальная проба](atlas/materials.md).

**C · Линия движения:** [07 Пара Туси](atlas/rolling.md) → [08 Ночной тираж](atlas/pressroom.md) → [09 Код Грея](atlas/gray.md).

На телефоне линии становятся вертикальными; для тёмной темы есть отдельная палитра. [Крупная схема](assets/wayfinding/map-light.svg) · [Дизайн, текстовый маршрут и исследование](atlas/wayfinding.md).
