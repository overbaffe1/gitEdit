# Личный тираж · Три числа

[Портфолио на экране](../../../templates/blocks/pocket-folio.md) · [только разметка для профиля](../../../templates/blocks/pocket-folio.md?plain=1) · [одна сторона A4 для печати](../../../assets/pocket-folio/issue-a4.pdf?raw=true).

На GitHub это две колонки обычного текста: короткое поле с числом и рассказ о работе рядом. Скопируй блок и замени числа, подписи и ссылки. Ссылка у числа должна открывать конкретный результат, а не отправлять посетителя искать его по репозиторию. Для этого варианта не нужны картинки, QR, Python или Actions.

## Как сложить выпуск

1. Напечатай **одну сторону A4**, альбомно, в масштабе **100 %**. Не включай режим «буклет»: страницы уже расставлены. Верхние четыре намеренно вверх ногами.
2. Наметь сгибы: вдоль пополам и поперёк на четыре равные части. Расправь лист. По **сплошной линии** сделай один разрез длиной 148,5 мм между первой и третьей поперечными складками. По пунктиру не режь.
3. Сложи лист вдоль рисунком наружу. Сдвинь короткие края к центру: прорезь раскроется ромбом, затем четыре крыла сойдутся крестом. Оберни их вокруг корешка так, чтобы сверху оказалась обложка **01 / 08**.
4. Перелистай: **02–03** — тепловой кадр, **04–05** — поставки, **06–07** — арфа. На заднике **08** — адрес профиля. QR каждого разворота ведёт ровно туда же, куда его число в README. В скачанном PDF QR также служит ссылкой, если просмотрщик поддерживает ссылки.

[Разворот 04–05 без принтера](../../../assets/pocket-folio/spread.png) вырезан из самого PDF и развёрнут для чтения. Бумажная страница после складывания — 74,25 × 105 мм.

## Выпустить своё портфолио

Единственный редакционный файл — [`issue.json`](issue.json). В нём три работы: каждая занимает две страницы, ещё две уходят на обложку и задник. `proof` — ссылка у числа и в QR, `also` — вторая ссылка в экранной версии. `marks` — ряды меток для левой страницы: `1` закрашенная точка, `0` кольцо, `|` струна. На единицу числа приходится один знак; поясни их смысл в `key`. Выбирай короткие названия, единицы и один абзац на работу.

Из корня клона (для полной сборки с указанными версиями пакетов — **Python 3.11+**):

```sh
# Напечатать только разметку, без дополнительных пакетов и без записи в файлы
python3 atlas/samples/pocket_folio/press.py --markdown

# Собрать весь выпуск в отдельный каталог
python3 -m pip install -r atlas/samples/pocket_folio/requirements.txt
python3 atlas/samples/pocket_folio/press.py --out my-edition
```

Для печати нужны [шрифты DejaVu](https://github.com/dejavu-fonts/dejavu-fonts/blob/0eda8a319c08835009849583cd090bb5b141ce25/LICENSE): Sans, Sans Bold, Serif и Sans Mono. По умолчанию наборщик ищет их в `/usr/share/fonts/truetype/dejavu`; другой каталог укажи через `--fonts`. Свою копию JSON можно передать через `--issue`. В выходном дереве появятся `templates/blocks/pocket-folio.md`, `assets/pocket-folio/issue-a4.pdf` и `assets/pocket-folio/spread.png`. Главный README не переписывается. После установки зависимостей наборщику не нужна сеть.

## Что именно посчитано

- **44** — пиксели эталона на одном [кадре VIIRS `AF_tr_000001`](https://github.com/overbaffe1/OMLP/blob/1a4aa4a40c62e6b5e06d3d1db4aa0c4e16094e7e/docs/figures/detection.png), не число пожаров и не точность модели. На бумаге они пересчитаны точками, без имитации карты.
- **35** — строки [расчётной сетки CosmoH](https://github.com/overbaffe1/CosmoH/blob/6cd3197af0412c22b782d90dbefde266cffdddad/solutions/fuel-contour/docs/evidence/response-grid.csv). Ряды: `delivery_share` от 0 до 1 с шагом 0,25; столбцы: `observed_after_days` 0, 30, 60, 90, 180, 270, 330. Заполнены только клетки с `after_shortage_t > 0`. Это результат модели снабжения, не наблюдение за реальной станцией.
- **13** — кости струн `str0`…`str12` в [готовой модели арфы](https://github.com/overbaffe1/MyWorkAiBrain/blob/3cbd01a7c9b6fa174be3dc6f96419df6f2db1db2/presentations/cantillon/models/glb/harp.glb), не общее число костей. [Анимация](https://github.com/overbaffe1/MyWorkAiBrain/blob/3cbd01a7c9b6fa174be3dc6f96419df6f2db1db2/presentations/cantillon/models/make_models.py#L497-L511) задаёт каждой струне своё время начала колебания.
