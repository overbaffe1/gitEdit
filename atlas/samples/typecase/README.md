# Typecase Dock · наборный склад

Один ящик, один причал и один текстовый курсор. [Скачай пробник](../../../assets/typecase/typecase.zip?raw=true), распакуй и открой `dock.html` в современном браузере. Никаких установок или запросов к серверу: [тот же TTF](../../../assets/typecase/dock.ttf?raw=true) уже внутри. В поле можно ввести, выделить, скопировать или стереть настоящие цифры.

| Набор | Что напечатается |
|---|---|
| `0` | Комната у входа. Можно начать с хода без нуля. Ноль в середине строки сбрасывает комнату. |
| `8` / `4` / `2` / `6` | Вверх / влево / вниз / вправо. Стена не пропустит; перед свободной клеткой ящик можно толкнуть. |
| `0866` → `086` | Отмена тупикового толчка. Удалена цифра, а не «передвинута назад» картинка. |

Доставка заканчивается печатью **OK**. В пробнике можно снять шрифт, чтобы прочитать маршрут; в любом другом редакторе выбери *Typecase Dock* для всей строки, включи **контекстные варианты** (`calt`) и набирай без пробелов. Цветные слои `COLR/CPAL` необязательны: под ними остаются одноцветные контуры. Вывод по одному символу за раз, например в сетке терминала, не подойдёт.

## Из каких деталей состоит шрифт

- В [`room.txt`](room.txt) `#` — стена, `@` — робот, `$` — ящик, `.` — причал. [`build_font.py`](build_font.py) обходит достижимые пары позиций. Рисунки собираются из общих печатных деталей, а не хранятся отдельными картинками.
- В первом контекстном правиле `GSUB` предыдущая комната остаётся на месте, а соседняя справа цифра становится новой комнатой. Набор продолжается слева направо, и только **после** прохода второе правило скрывает все комнаты, кроме последней. У пустого глифа нулевая ширина. Так необязательно хранить все возможные строки или ограничиваться одним заученным маршрутом.
- Первым нажатием, столкновением, сбросом и победой заведует шрифт. В [`dock.html.in`](dock.html.in) нет копии карты или движка: экранные кнопки телефона редактируют строку ввода. Отключи JavaScript — ручной набор, удаление и переключение шрифта по-прежнему работают.
- Для [GIF](../../../assets/typecase/delivery.gif) и [неподвижной пары оттисков](../../../assets/typecase/proof.png) [`publish.py`](publish.py) даёт HarfBuzz строку ходов и печатает выбранный **из готового TTF** глиф через FreeType. Рисунок игровой доски не дублируется в рендерере.

## Пересборка из корня репозитория

Нужны Python 3.11+, FreeType с поддержкой `COLR` и системные шрифты DejaVu для подписей к оттискам. Зависимости удобно установить в виртуальное окружение.

```sh
python3 -m pip install -r atlas/samples/typecase/requirements.txt
python3 atlas/samples/typecase/publish.py
python3 -m unittest discover -s tests -p test_typecase.py -v
```

`publish.py --out /tmp/typecase` напечатает четыре файла отдельно от репозитория. Если нужен только шрифт, достаточно FontTools и `python3 atlas/samples/typecase/build_font.py` (у этого скрипта `--out` задаёт **файл** TTF). Приём перехода между сценами нашли у [автора Fontemon](https://github.com/mmulet/code-relay/blob/3a6b651445aac3b8dc6fad64b4234b6950828dbe/markdown/HowIDidIt.md); [другие примеры и разбор](../../inspiration.md). Уровень, правила сборки и все игровые знаки здесь свои.
