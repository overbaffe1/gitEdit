### Забрать вариант в свой репозиторий

1. Сохрани [этот SVG](../../../assets/switchboard/wide-coral.svg) в своём проекте как `assets/readme-card.svg`. Для исходных байтов используй Raw/Download, а не HTML-страницу файла.
2. Скопируй Markdown ниже в свой корневой README и замени демонстрационный текст.

```markdown
<img src="assets/readme-card.svg" width="100%" alt="Обложка проекта: название и геометрический знак.">

## Название проекта

Одно предложение: что делает проект и кому помогает. Замени этот пример своим текстом.
```

[Тот же фрагмент отдельным TXT](../../../assets/switchboard/snippets/wide-coral-brief.txt). Это текст для ручного копирования, не автоматическое изменение файла и не команда в буфер обмена.

Цвет выбран в самом SVG и не переключается автоматически с темой GitHub. Размеры — подсказки для рендера; узкий экран ограничивает картинку шириной контейнера. SVG не содержит скриптов и внешних ресурсов.
